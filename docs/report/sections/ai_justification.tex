\section{AI Justification}
\label{sec:ai-justification}

\todobox{\textbf{Owner: Fatima.} Explain why this problem needs machine learning rather than hand-written rules. Cover at least:
\begin{itemize}[leftmargin=1.5em, topsep=2pt]
  \item Hand shape varies across people: hand size, finger length, skin tone and how each person forms the same letter.
  \item Lighting, background, camera angle and distance change the image even when the sign is the same.
  \item Some letters look very similar (for example closed-fist shapes that differ only in thumb position), so small differences decide the class.
  \item Why rules are impractical: show what a rule-based approach would need (for example fixed thresholds on finger angles per letter) and why it breaks under the variation above.
  \item What a learned model provides instead: it learns the decision boundaries from labelled examples and can be evaluated on people it has not seen.
\end{itemize}
Use no accuracy numbers here; results belong to Deliverable 2.}
